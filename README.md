# TNSAIML_Training

# Retail Sales Forecasting Using Machine Learning

## Project Description
This project predicts future retail sales using the Linear Regression algorithm.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

## Features
- Retail sales dataset analysis
- Data preprocessing
- Linear Regression model training
- Model evaluation using MAE, MSE and R2 Score
- Future sales forecasting
- Graphical visualization using Streamlit

## How to Run

1. Install required packages:
   `pip install -r requirements.txt`

2. Run the backend:
   `python backend.py`

3. Run the Streamlit application:
   `streamlit run app.py`
